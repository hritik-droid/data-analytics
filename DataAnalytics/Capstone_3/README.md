# Capstone 3 – Analysis with Power BI

## Project Overview

This project was completed as part of the Year Up United Data Analytics Training Academy Week 12 Capstone. The goal was to analyze four years of sales data for EmporiUm, a virtual student bookstore, using Power BI.

The report provides insights into sales performance, trends over time, product categories, regional sales distribution, and top-selling books within the assigned sales region.

## Objectives

The primary objectives of this project were to:

- Clean and transform raw sales data using Power Query.
- Build a data model suitable for business analysis.
- Create meaningful visualizations in Power BI.
- Identify sales trends and business insights.
- Present findings through an interactive dashboard.
