# Capstone 3 – Analysis with Power BI

## Project Overview

This project was completed as part of the **Year Up United Data Analytics Training Academy – Week 12 Capstone**.

The objective of this project was to analyze EmporiUm's sales data using **Microsoft Power BI** to identify sales trends, compare product category performance, and provide business insights through an interactive dashboard.

For this capstone, my assigned sales region was the **East Region**, which includes **New York and Connecticut**.

---

# Project Objectives

The objectives of this project were to:

* Import and clean raw sales data using Power Query.
* Create relationships between multiple data tables.
* Build an interactive Power BI dashboard.
* Analyze sales performance over time.
* Compare sales across product categories.
* Analyze sales performance within the East region.
* Identify the top-selling general books and their authors.
* Present business insights that support data-driven decision-making.

---

# Data Sources

The dashboard was created using the following files:

* **Capstone3_Sample_Sales.xlsx**

---

# Data Preparation

The following data preparation steps were completed before building the dashboard:

* Imported all Excel tables into Power BI.
* Imported the bookstore inventory text file.
* Corrected data types.
* Removed invalid and unnecessary records.
* Built relationships between:

  * Store Sales
  * Online Sales
  * Products
  * Store Locations
  * Management Team
  * Book List
* Cleaned the book titles and author information to create a relationship between books and authors.

---

# Dashboard Overview

## Page 1 – EmporiUm Sales Dashboard

This page provides an overview of company sales performance.

Visualizations include:

* Sales Trend Line Chart
* Sales by Product Category Column Chart
* Sales performance summary

This page allows management to monitor overall business performance and identify sales trends over time.

---

## Page 2 – East Region Sales Analysis

This page focuses on the **East Region**, which includes **New York and Connecticut**.

Visualizations include:

* Donut Chart showing sales by state within the East region
* Top-Selling General Books table
* Author names for bestselling books

The page allows regional managers to compare state performance and identify the highest-selling books in the East region.

---

# Business Insights

The dashboard provides several valuable insights:

* Sales trends can be monitored over time to identify seasonal patterns.
* Product category comparisons help identify high-performing categories.
* Regional filtering allows managers to analyze sales for New York and Connecticut separately from other regions.
* The Top-Selling Books report highlights popular books and authors, supporting better inventory and purchasing decisions.
