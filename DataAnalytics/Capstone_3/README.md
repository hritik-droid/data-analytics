# Capstone 3 – Analysis with Power BI

## Project Overview

This project was completed for the Year Up United Data Analytics Training Academy Week 12 Capstone. The objective was to analyze EmporiUm sales data using Microsoft Power BI to identify sales trends, product performance, and regional sales insights over multiple years.

My assigned sales region was **East**.

## Objectives

The goals of this project were to:

* Import and clean sales data using Power Query.
* Build a relational data model in Power BI.
* Analyze sales trends over time.
* Compare sales performance by product category.
* Analyze sales performance within the East region.
* Identify the top-selling general books and their authors.
* Create an interactive dashboard to support business decision-making.

## Data Sources

The project used the following files:

## Dashboard Pages

### Page 1 – EmporiUm Sales Performance Dashboard

This page includes:

* Sales Trend Line Chart
* Sales by Product Category Column Chart
* Overall sales performance summary

### Page 2 – East Region Sales Analysis

This page includes:

* Donut Chart showing sales by state within the East region
* Top-Selling Books table including author names
* Regional sales analysis for management

## Key Insights

* Sales performance changes throughout the reporting period, highlighting seasonal trends.
* Product categories contribute differently to overall revenue.
* Massachusetts represents the sales activity within the East region in this dataset.
* The report identifies the highest-selling general books and their corresponding authors.
* Interactive filtering allows managers to quickly explore sales information.
